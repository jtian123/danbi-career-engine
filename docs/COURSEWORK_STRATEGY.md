# Coursework strategy

Keep graduate education near the top for a current student. Select up to three courses connected to a target role. Public course metadata is drawn from the [USC ISE handbook](https://ise.usc.edu/wp-content/uploads/2026/08/2026-2027-ISE-Handbook.pdf); requirements can depend on admission year.

Catalog offerings appear as **Relevant program curriculum**. Completed, in-progress and confirmed-planned labels need evidence specific to the person and course. A program catalog, a blank homework template or a general student biography cannot establish attainment. Curriculum selection does not add skills or completed projects.

The public fixture bank uses program-offering-only status for every course. It makes no assertion that any person enrolled in or completed them.
